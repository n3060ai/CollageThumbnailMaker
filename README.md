コラージュサムネ作成 (Collage Thumbnail Maker)

ブラウザ上で大量の画像から綺麗なコラージュ・サムネイル画像を簡単に生成できる軽量Webツールです。

HTMLファイル1つで完結しており、サーバーへの画像アップロードは一切行われません。すべての処理が端末（ブラウザ）内で完了するため、プライバシー面でも安心・安全かつ高速に動作します。

🌟 特徴

🔒 完全ローカル処理（プライバシー重視）

画像は端末内でキャンバス描画処理されます。外部サーバーに送信・アップロードされることはありません。

📁 フォルダ丸ごとドロップ対応

フォルダをドラッグ＆ドロップするだけで、中の画像をまとめて読み込んでコラージュを作成できます。

🎨 多彩なレイアウトパターン

大＋小（ヒーロー型）: 注目させたいメイン画像を大きく配置し、周囲を他の画像で埋めるレイアウト。

中央ヒーロー: メイン画像を中央に大きく配置。

均等グリッド: 画像を整然と均等サイズで並べるレイアウト。

元の比率で敷詰: 画像の元の縦横比を崩さずに綺麗に敷き詰めるレイアウト。

ランダム分割: パズル状に不規則に分割・配置。

⚙️ 豊富なカスタマイズ機能

アスペクト比変更（1:1、4:5、3:4、9:16、4:3、16:9）

出力解像度の選択（1200px / 1600px / 2400px）

画像同士の「隙間（ギャップ）」調整

メイン画像の選択＆配置場所の切り替え（右上、右下、左上、左下、中央）

総枚数バッジの表示/非表示切替

トリミング位置（上寄せ/中央寄せ）の微調整

ワンタップでのランダム「シャッフル」

⚡ 超軽量＆オフライン対応

外部ライブラリ（React, Vue, jQuery等）非依存の純粋なHTML/CSS/JavaScript（Vanilla JS）。

ファイルをダウンロードすれば、インターネット接続がない環境（オフライン）でも動作します。

🚀 使い方

1. 起動する

index.html をお持ちのブラウザ（Chrome, Safari, Edge, Firefoxなど）で開くだけで起動します。

2. 画像を読み込む

点線エリアに画像ファイルまたは画像が入ったフォルダをドラッグ＆ドロップします。

または「フォルダを選択」「画像を選択」ボタンからファイルを選択します。

3. レイアウト・デザインを調整する

上部のパターン一覧（タップ選択）から好みのレイアウトを選びます。

メインにする画像、アスペクト比、出力サイズ、列数、隙間などを操作パネルで調整します。

「シャッフル」ボタンを押すと、サブ画像の配置順をランダムに変更できます。

4. 保存する

PCの場合: 「ダウンロード」ボタンを押すと collage.jpg として保存されます。

スマホ・タブレットの場合: 生成された画像を長押しして「写真に保存」または「画像を保存」を選択してください。
